# Day Trading Skills

Collection de skills Claude pour le day trading.

## Structure

```
skills/
  <nom-du-skill>/
    SKILL.md        # instructions du skill (frontmatter name + description)
    references/     # docs complémentaires (optionnel)
    scripts/        # scripts utilitaires (optionnel)
```

## Avertissement

Ces skills sont des outils d'aide à l'analyse, pas des conseils financiers.
Le day trading comporte un risque élevé de perte en capital.
